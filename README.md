# 🎥 YouTube Video Manager (CLI)

A simple Python command-line application to manage YouTube videos.  
You can **add**, **list**, **update**, and **delete** videos, all stored inside a JSON file (`youtube.txt`).

This is a beginner-friendly CRUD project to practice:
- Python functions
- File handling
- JSON data management
- Basic CLI interactions

---

## 🚀 Features

✔ List all saved YouTube videos  
✔ Add a new video (name + time)  
✔ Update any existing video  
✔ Delete a video  
✔ Automatically saves data inside a JSON file
